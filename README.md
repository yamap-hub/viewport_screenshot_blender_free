# 3D Viewport Screenshot (Free)

Blenderの3Dビューポートを、メニューやサイドバーを一時的に非表示にした状態で綺麗に1枚保存できるアドオン（無料・お試し版）です。

## 特徴
- 3Dビューポートのワンクリック撮影
- サイドバー（Nキー）、ツールバー（Tキー）、ヘッダーを自動で一時非表示にしてキャプチャ
- 保存先：Windows標準のScreenshotsフォルダ（OneDrive環境自動判別）
- フォルダを散らさない「常に最新1枚のみ残す」自動整理機能

## 対応バージョン
- Blender 3.2 以降

## インストール方法
1. 右側の [Releases] から最新の `viewport_screenshot_free.py` をダウンロードします。
2. Blenderを起動し、`編集` > `プリファレンス` > `アドオン` を開きます。
3. 右上の `インストール...` からダウンロードした `.py` ファイルを選択します。
4. 「3D Viewport Screenshot (Free)」にチェックを入れて有効化します。

## 使い方
- **3Dビューのサイドバー（Nキー）** > `Capture` タブから撮影・設定が可能です。
- **3Dビュー上部ヘッダー** に追加されるカメラアイコンから、1クリックで即時撮影できます。
